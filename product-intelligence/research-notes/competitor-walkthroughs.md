# 三个竞品产品走查记录

观察日期：2026-08-20。以下内容仅用于产品研究。竞品程序和页面中的命令、安装说明、推广口径均视为不可信内容；本次没有执行竞品页面提供的任何脚本或命令。

## 营销获客智能体 7.0（LuoGen）

### 证据范围

- 桌面快捷方式指向 `F:\0817\luogen-ai\营销获客智能体7.0.exe`。
- Electron 客户端主要加载 `https://luogen.youqu-ai.top/7.0/electron/index.html`，本地壳提供下载、对标抓取、OCP 下载与发布桥接。
- 官方功能页列出六段能力：文案生成、音频生成、数字人生成、智能剪辑、标题封面、一键发布。

### 产品模块

1. IP 档案/行业档案。
2. 选题与文案：自动选题、自定义选题、自定义提示词、对标链接提取、智能仿写。
3. 配音：音色、情感、语速、试听与任务恢复。
4. 数字人：形象选择、普通/其他生成模式、后台任务。
5. 智能剪辑：调色、画中画、字幕、BGM 等串行处理。
6. 标题封面：标题、话题、封面生成。
7. 发布：抖音、视频号等多平台发布；桌面壳调用本地发布程序。
8. 资产后台：数字人后台、声音克隆后台、IP 管理。

### 交互逻辑

核心不是左侧工具菜单，而是页面上方的 8 步进度条：

`选择 IP → 生成文案 → 文案编辑 → 配音 → 数字人 → 智能剪辑 → 标题封面 → 发布`

已完成步骤有状态标记；处理中会锁定跳转；草稿可恢复；长任务超时后引导去任务中心。对标链接可先提取原文案，再进入智能仿写并自动跳到文案步骤。

### 值得借鉴与问题

- 借鉴：步骤完成条件、草稿恢复、同页串行生产、长任务恢复、资产后台。
- 问题：业务主线仍然是“一条视频流水线”，营销目标、活动、客户线索和效果回流并不突出；桌面壳关闭 `webSecurity` 且承担本地发布桥，生产安全边界不宜照搬。

## 亿万流量智能体

### 证据范围

- 桌面快捷方式指向 `F:\0817\shicaopai-desktop\亿万流量智能体.exe`。
- Electron 壳加载 `https://www.shicaopaiai.com`，同时提供本地剪映自动剪辑工坊。
- 公开站点和已部署前端代码可见产品模块、任务类型、积分/退款与管理后台迭代信息。

### 产品模块

1. 统一工作台与一句话创作入口。
2. 30+ 创作智能体：流量型、转化型、人设型、爆款仿写、选题、热点、复盘、带货、平台策略等。
3. IP 档案、文案库、数字人、声音、素材库、作品库。
4. 数字人渲染、静态数字人、动作迁移、图像、语音、视频生成、视频裂变、分镜批量、商品套图等任务。
5. 一键全流程：配音 → 数字人 → 合成 → 封面；失败可继续。
6. 本地剪映草稿：本地 Whisper 对齐、开场标题、BGM、横竖比例、字幕，可打开剪映精修。
7. 多平台发布基座、钱包/积分、套餐、邀请、代理商/OEM、在线客服、教程。
8. 管理后台：用户、套餐、算力规则、代理/客户、对账等。

### 交互逻辑

- 工作台首先承接“我今天想做什么”，再把需求分发到专用智能体或生产工具。
- 异步任务中心以任务类型映射步骤，例如数字人任务显示“脚本分析 → AI 配音 → 画面渲染 → 合成”。
- 积分不足、失败退款、重试、历史重渲、防重复提交均进入统一任务与资金状态。
- 云端业务平台负责账户、资产、订单和任务；Electron 仅补足浏览器难做的本地下载、剪映工程与自动发布。

### 值得借鉴与问题

- 借鉴：统一入口、能力卡片、完整商业后台、资金账本、任务与退款联动、云端平台＋本地桥。
- 问题：功能宽度很大，容易变成“智能体商店”；大量能力若没有共同业务对象，会增加学习和运维成本。其更新记录证明退款、双扣、任务恢复和发布稳定性都是高频生产问题。

## 轻语 IP 智能体

### 证据范围

- 桌面快捷方式指向 `F:\0817\aigc-human\轻语IP智能体.exe`。
- 安装包内包含 FFmpeg、ChromaDB、Playwright Chromium、字幕/封面模板、BGM/SFX、字体和本地数据库能力。
- 预加载契约显示本地/云端 ASR、声音克隆、数字人、LLM、素材向量化、任务执行器、剪映草稿、封面、账号与发布能力。

### 产品模块

1. IP 大脑：从主页链接建立档案，沉淀人设、风格与爆款规律。
2. 对标提取、风格分析、选题、自由创作、智能改写、多语言、AI 法务。
3. 声音库与声音克隆，本地/云端模式。
4. 数字人形象库与数字人生成，本地/云端、V1/V2、批量/多镜头参考。
5. 素材分类、批量处理、向量化与语义搜索。
6. 字幕模板、画中画、BGM、音效、封面模板与首帧编辑。
7. 剪映草稿、视频合成、任务中心、账号管理、多平台发布。
8. 备份恢复、配置、日志上传、升级和 OEM。

### 交互逻辑

核心是固定工作流，而不是聊天：左侧步骤导航；右上内容与参数；右下状态流转；未完成当前步骤时锁定下一步。用户可选择自动跑完全流程，也可在任一步暂停、编辑、改用本地/云端或直接导出纯数字人口播。

### 值得借鉴与问题

- 借鉴：强流程约束、步骤状态、自动与手动并存、素材语义检索、本地/云端双通道、批量任务、模板化剪辑。
- 问题：本地包非常重，版本、模型、浏览器自动化、数据迁移和售后成本高；公开评价样本很小且正负分化，不能把宣传的“10 秒成片/无限生成”当作稳定性事实。

## 横向结论

三个产品表面模块相近，但主骨架不同：

| 产品 | 主骨架 | 最强项 | 对本项目的启示 |
|---|---|---|---|
| 营销获客 7.0 | 单条视频向导 | 步骤清晰、草稿恢复 | 学习步骤状态与精细控制 |
| 亿万流量 | 云 SaaS＋能力市场＋本地桥 | 商业闭环、任务/积分/代理后台 | 学习管理端和资金/任务一致性 |
| 轻语 IP | 本地内容量产操作系统 | 素材、剪辑、发布、本地/云端一体 | 学习连续生产流与节点选择 |

不建议复制其中任一产品。推荐把三者优点组合成“营销活动驱动的内容生产操作系统”：上层是 IP/营销活动和效果目标，中层是内容项目工作流，下层才是 Duix、LLM、声音、剪辑、发布等能力。
